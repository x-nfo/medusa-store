Domain Glossary (wajib untuk agent)
Istilah	Definisi
Cart	Keranjang belanja sebelum order
Variant	Kombinasi size/warna pada produk
Reservation	“Menahan stok” sementara untuk mencegah oversell
Fulfillment	Proses pengiriman (packing → shipment)
AWB/Resi	Nomor resi pengiriman
TrackingLink	Objek penyimpan tracking number + URL
Payment Session	Sesi pembayaran (Midtrans Snap token/redirect)
Midtrans Snap	Hosted payment page / popup flow
Midtrans webhook	Notifikasi status transaksi ke backend
RajaOngkir Delivery/Order	API membuat shipment & generate AWB/label
Flash sale	Promo berjangka waktu dengan traffic tinggi
